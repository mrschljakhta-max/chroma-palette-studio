# CHROMA · Premium Brand Preview Studio

Інтерактивний конструктор із 12 палітрами та демонстрацією їхнього застосування.

## Premium v2
- **Усі носії:** огляд канцелярії, сайту та вивіски.
- **Канцелярія:** бланк, візитка, конверт з автоматичною зміною кольорів.
- **Сайт:** адаптивний макет персонального бренду Наталії.
- **Вивіска:** фасад у режимах «День» та «Ніч».
- **Порівняти:** A/B-перегляд двох палітр на тих самих носіях, кнопка застосування B.
- **Обрати палітру:** збереження вибору та кольорів у цьому браузері.
- **Інші макети:** оригінальні лендінг, дашборд і магазин.
- **Редактор:** HEX, color picker, 7 ролей кольорів, контраст, улюблені, CSS-копіювання і JSON.

## Файли
`index.html` — існуючий застосунок, збережені 12 пресетів та підключення нового модуля.
`assets/premium.css` — преміальні матеріали, сцени та адаптивність.
`assets/premium.js` — A/B-порівняння, взаємодія з носіями, день/ніч, обрана палітра.

Пресети редагуються в єдиному масиві `PALETTES` у `index.html`. Premium-візуалізації використовують ті самі 7 кольорів.

## Важливо
Це дизайнерські макети — не фотографії реального друку чи фасаду. Назва «Наталія» використана як демонстраційний бренд. Сторінка не надсилає заявки.
Палітри, обране та ручні зміни зберігаються лише локально в браузері; для перенесення на інший пристрій експортуйте JSON.

## Розгортання

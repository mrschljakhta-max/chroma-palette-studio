# CHROMA — Palette Studio

Готовий односторінковий сайт для вибору кольорової палітри.

## Запуск
Відкрийте `index.html` у браузері. Для публікації розмістіть його в корені репозиторію з увімкненим GitHub Pages або завантажте на будь-який статичний хостинг. Сервер і збірка не потрібні.

## Як змінювати пресети
У файлі `index.html` знайдіть у нижній частині коду масив JavaScript `const PALETTES = [...]`. Кожна палітра має `id`, `name`, `description`, `tag`, `mode` (`dark`/`light`) і 7 кольорів у `colors`: `bg`, `surface`, `text`, `muted`, `primary`, `accent`, `border`.

## Можливості
- Готові палітри, улюблені та власне коригування HEX.
- Живий перегляд лендінгу, аналітичного дашборда та магазину.
- Режими десктоп/мобільний, перевірка базової контрастності WCAG AA.
- Експорт JSON та копіювання CSS-змінних.
- Збереження вибору і персональних налаштувань у `localStorage` браузера.

Примітка: сайт працює локально без сторонніх бібліотек та підключення до інтернету.
